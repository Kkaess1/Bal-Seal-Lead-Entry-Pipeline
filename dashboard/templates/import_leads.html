Choose the workbook

Any layout works. The AI reads the whole workbook — every sheet, title rows, combined columns like “City, State ZIP” — and fills in each lead's contact, company, location, rank and market. Everything it reads is checked against the row it came from, and any column it did not use is kept word for word in the lead's details.

Every row becomes a lead unless it is explicitly marked Cold. Uploading the same file again does not create duplicates. Every lead lands on Pending Review and still has to be approved.
